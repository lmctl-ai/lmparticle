# CI

Same shape as lmnum, lmbio and lmplot: five jobs (linux-x64, linux-arm64, macos-arm64, macos-x64,
windows-x64), each running `scripts/sync-deps.sh` (a no-op here), installing `@lmctl-ai/lmctl@0.2.369` for
`lmscript`, running `./test.sh` with `LMPARTICLE_TEST_NETWORK=1` (the lmplot pipelines download lmplot's
release), then uploading `lmparticle-<platform>[.exe]` plus LICENSE and THIRD_PARTY_NOTICES. A `v*` tag adds the
release job, which checks `--version` against the tag and attaches the binaries with `gh release`.

First run, all five green on the first push (job wall time incl. build and `test.sh`): macos-arm64 1.2 min, windows-x64 1.2 min, linux-x64 1.4 min, macos-x64 1.4 min, linux-arm64 1.1 min.
